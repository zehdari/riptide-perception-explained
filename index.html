riptide_perception, chapter by chapter

Talos found every prop in that run with the two halves of riptide_perception: a detector that finds props in each camera image, and a map that turns those detections into where each prop really is.

Talos is the Underwater Robotics Team's competition AUV. Every RoboSub task starts with one question: where exactly is the thing? riptide_perception answers it. This site explains that code for new team members. You need some Python and high-school vectors; the maths is on one page.

  • Vision (tensor_detector): looks at one image at a time and says what it sees and where, relative to the camera.
  • Mapping (riptide_mapping): collects detections over the run into a course map, and publishes each prop as a coordinate frame for the behaviour trees and the controller.

The run above

  • Grey shapes: props where Nereus put them. Dashed rings: where the map has them.
  • Filled dots with ellipses: confirmed estimates with 2σ uncertainty. Hollow dots: unconfirmed.
  • Small dots: single detections, with a line along the measured surface normal. Little circles: objects in another prop's frame (torpedo holes, table items, bin targets).
  • Camera card: what the camera saw, with YOLO's masks.

This is one run of RepairCompMpcTree, the competition tree, on a course placed exactly where the map says. Talos does gate, slalom, torpedoes, table, bins and magnets, then swims home. Each step waits for a precise enough estimate (thresholds in Chapter 9). Chapter 10 has the run as video, and a second run on a moved course where two things go wrong.
